# 전체 단어 목록을 앱에 번들하지 않는다

단어는 **런타임에 외부 API에서 가져와 로컬에 캐시**한다. 앱 바이너리에는 전체 목록을 넣지 않는다. 단, 첫 실행이 오프라인이어도 아무것도 못 하도록, 라이선스가 안전한 소수의 시드 단어만 별도로 동봉한다.

## 이유

이 앱은 개인 프로젝트로 공개 배포한다. 전체 단어 목록을 번들하면 그 목록의 라이선스가 앱 배포의 라이선스가 된다.

- **Oxford 3000/5000** — 개인 학습 사용은 무료지만 앱에 번들해 재배포하는 것은 조건 위반이다. 목록을 "참고"로 넣는 것도 애매하다.
- **Wiktionary 파생 데이터** — CC BY-SA. 앱에 실으면 저작자 표시 의무가 발생하고, 동일 라이선스 저작물 취급 논쟁까지 열린다.

런타임 fetch + 캐시로 두면 앱은 데이터를 distribute하지 않는다. 책임이 API 서비스에 남는다.

## 시드 단어는 별개다

30~50개의 시드 단어는 **직접 고른 것**이므로 라이선스 문제가 없다. 오히려 타인의 글이나 창작물을 복사하지 않아야 한다. 범용 빈도가 높은 기본 단어 위주로, 예문은 우리가 직접 쓴다.

이 선택의 대가는 분명하다: 첫 실행에 네트워크가 없으면 아무것도 못 한다. 시드 단어로 그 구멍만 막고, 전체 카탈로그는 네트워크에 의존한다.

## 대안의 함정

"위키셔너리 덤프를 파싱해서 번들하자. 오프라인 완전, 최신, 라이선스도 명확하다." 직관적으로 좋아 보이지만 CC BY-SA를 앱 배포에 얹는다는 사실은 그대로다. 그리고 덤프 파싱 스크립트는 위키 dumping 방식이 바뀔 때마다 고쳐야 하는 유지보수 항목이 된다. "나중에 라이선스가 문제되면 그때 배움"로 미루는 건 공개 배포에서 뒤집히기 어려운 결정이다.
